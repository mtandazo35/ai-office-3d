            Conectar Claude Code con la oficina

            1. Instala los hooks (una vez). Desde la carpeta del repositorio: 
              docker compose run --rm instalar
              Añade a ~/.claude/settings.json hooks de tipo http que envían cada evento a esta oficina, con un token propio. Guarda antes una copia del archivo.
            2. Reinicia las sesiones de Claude Code (terminal o VS Code) para que carguen los hooks. Comprueba con /hooks.
            3. Trabaja como siempre. Cada sesión aparece como un escritorio. Pulsa sobre él para ver qué hace y darle órdenes.

            Para quitarlo: docker compose run --rm instalar --desinstalar. Las órdenes pasan por el sistema de permisos normal de Claude Code: no le dan permisos nuevos.
